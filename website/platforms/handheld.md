# 掌机和手柄界面

在 ROG Ally、Legion Go、Steam Deck 这类掌机上，Ludonimbus 有两样为手柄准备的东西：启动游戏时的全屏提示，和一个只用手柄就能操作的界面。

两样都在「设置 → 掌机」里设置。

## 启动游戏时的提示

从 Steam 启动游戏时偶尔需要你做选择，例如[存档冲突](../sync/conflicts.md)，或者正在下载更新的存档时选[「先玩本机的」](../sync/how-it-works.md#waiting)。在掌机上，这些提示用全屏窗口显示，每个按钮对应手柄上的一个键，也可以用方向键选好后按 A。

「启动游戏时的提示」有三个选项：

| 选项 | 意思 |
|---|---|
| 自动 | 从 Steam 大屏幕模式或游戏模式启动时用全屏窗口，其他时候用普通的对话框 |
| 总是全屏 | |
| 总是用系统对话框 | |

## 手柄界面

一个全屏的游戏库，只用手柄：

- **游戏库**：所有游戏和它们的同步状态。只在云端的游戏也在。
- **游戏页**：上次同步的时间、「立即同步」，以及和桌面上同一份[存档列表](../sync/versions.md)：选一份，A「设为当前」，X「发到…」。换掉以后可以「撤销」。
- **存档冲突**：直接在这里选「使用云端存档」或「使用本机存档」。
- 另一个版本有更新的存档时，会提示可以「发到这个版本」。

添加游戏、连接云盘这类需要打字和选文件的事，还是在桌面界面里做；手柄界面的设置页里有「切换到桌面界面」。

### 怎么打开

- 「设置 → 掌机 → 进入手柄界面」。
- **从 Steam 游戏库打开**：在「设置 → 掌机」点「加到 Steam」，Ludonimbus 会作为一个非 Steam 游戏出现在 Steam 游戏库里（需要重新打开 Steam）。在大屏幕模式或游戏模式里启动它，就是手柄界面。
- **从 Xbox 应用打开**（Windows 掌机）：「我的游戏库 → 添加游戏」，选 Ludonimbus 安装文件夹里的 `ludonimbus-app.exe`，启动参数填 `--handheld`。

::: tip
从 Xbox 应用启动的游戏不经过 Steam，存档只在游戏退出后由托盘里的 Ludonimbus 上传。想要启动前也拉取最新的存档，从 Steam 启动。
:::
