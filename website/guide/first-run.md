# 首次使用引导

第一次打开 Ludonimbus 时（还没有连接云盘、也没有添加游戏），会弹出一个引导，带你完成最基本的设置。每一步都可以跳过，右上角可以直接关掉；以后在「设置 → 关于 → 重新打开新手引导」里可以再打开。

## 1. 欢迎

介绍 Ludonimbus 做什么。下面可以切换界面语言（简体中文 / English），以后也可以在[设置](../reference/settings.md#language)里改。

![首次使用引导：欢迎](/screenshots/zh-CN/guide-welcome.png)

## 2. 你想用来做什么

可以多选：模拟器游戏、重编译 / 移植游戏、给 Steam 里的第三方游戏加云存档、在多台设备之间同步存档。Ludonimbus 会按你的选择调整后面的推荐和提示。这些选择只保存在本机。

![首次使用引导：选择用途](/screenshots/zh-CN/guide-usage.png)

## 3. 连接云盘

列出适合你的云盘：中文界面先推荐[夸克网盘](../clouds/quark.md)、坚果云和 Google Drive，其他的在「更多云盘…」里；连接方式和设置页完全一样，见[怎么选云盘](../clouds/index.md)。连好后点「下一步」。

选了「在多台设备之间同步存档」时，每台设备都要连接**同一个**云盘，见[多台设备](../sync/devices.md)。

![首次使用引导：连接云盘](/screenshots/zh-CN/guide-cloud.png)

## 4. 封面（可选）

填写 SteamGridDB 的免费 API Key 后，把游戏加入 Steam 时可以自动配好封面、背景、Logo 和图标。按页面上的三步获取 Key，详细说明见[封面与 SteamGridDB](../steam/artwork.md)。不填也可以，以后在设置里填，或者给游戏选本地图片。

![首次使用引导：封面](/screenshots/zh-CN/guide-art.png)

## 5. 完成

显示哪些已经配好、哪些跳过了，并按你选的用途给出下一步建议。点「扫描本机游戏」会直接打开[扫描本机](../games/scan.md)，开始添加游戏。

如果 Ludonimbus 对你有帮助，欢迎在完成页点「在 GitHub 上点 Star」支持这个项目。

![首次使用引导：完成](/screenshots/zh-CN/guide-done.png)

## 接下来

照着[快速上手](./quick-start.md)的第 2 到 4 步，把游戏加进来并开启 Steam 自动同步。
