# S3 兼容存储

很多对象存储都兼容 Amazon S3 的接口：阿里云 OSS、腾讯云 COS、Cloudflare R2，以及可以装在 NAS 上的 MinIO。按量付费的服务存档很小，费用一般很低。

## 通用步骤

1. 先在对应服务的控制台里**建好一个 Bucket**，并创建一对访问密钥（Access Key 和 Secret Key）。Ludonimbus 不会自动创建 Bucket。
2. 打开「设置 → 云盘」，在「S3 兼容存储」那一项点「填写 S3 信息…」。
3. 在「常用」里点你用的服务（MinIO（NAS）、阿里云 OSS、腾讯云 COS、Cloudflare R2），Ludonimbus 会填好 Endpoint 的格式，并显示注意事项。
4. 填写：
   - **Endpoint**：服务地址，尖括号 `<…>` 里的部分换成你自己的。
   - **区域**：可以留空（默认 `us-east-1`）。
   - **Bucket**：第 1 步建的 Bucket 名称。
   - **路径前缀**：存档放在 Bucket 里的哪个前缀下，默认 `Ludonimbus`。
   - **Access Key**、**Secret Key**。
   - **路径风格**：用 Endpoint/Bucket 的形式访问，MinIO 等需要打开。
5. 点「测试连接」，再点「连接」。

Secret Key 保存在本机的 Windows 凭据管理器里，断开时删除。

::: tip 用权限最小的密钥
建议为 Ludonimbus 单独创建一个只能访问这个 Bucket 的子账号或令牌，不要用主账号密钥。
:::

## MinIO（NAS） {#minio}

| 项目 | 填写 |
|---|---|
| Endpoint | `http://<NAS 地址>:9000`（MinIO 的 API 端口，不是网页控制台的端口） |
| 区域 | 留空 |
| 路径风格 | **打开** |

在 MinIO 控制台里创建 Bucket 和 Access Key。

## 阿里云 OSS {#aliyun-oss}

| 项目 | 填写 |
|---|---|
| Endpoint | Bucket 所在地域的地址，例如杭州是 `https://oss-cn-hangzhou.aliyuncs.com` |
| 路径风格 | 关闭 |

建议用只允许访问这个 Bucket 的 RAM 子账号的 AccessKey。

## 腾讯云 COS {#tencent-cos}

| 项目 | 填写 |
|---|---|
| Endpoint | Bucket 所在地域的地址，例如广州是 `https://cos.ap-guangzhou.myqcloud.com` |
| 区域 | 和 Endpoint 一致，例如 `ap-guangzhou` |
| Bucket | **要带上 `-APPID` 后缀**，例如 `ludonimbus-1250000000` |
| 路径风格 | 关闭 |

密钥在「访问管理 → API 密钥管理」里创建，建议用子用户的密钥。

## Cloudflare R2 {#cloudflare-r2}

| 项目 | 填写 |
|---|---|
| Endpoint | `https://<账号 ID>.r2.cloudflarestorage.com` |
| 区域 | `auto` |
| 路径风格 | 关闭 |

在 R2 里创建一个有对象读写权限的 API 令牌，会得到 Access Key ID 和 Secret Access Key。

## 连不上？ {#troubleshooting}

| 现象 | 可能的原因 |
|---|---|
| Bucket 不存在 | Bucket 名称写错；腾讯云 COS 少了 `-APPID` 后缀；Endpoint 和 Bucket 不在同一个地域 |
| 签名错误 / 拒绝访问 | Secret Key 填错；区域和 Endpoint 不一致；密钥没有这个 Bucket 的权限 |
| 连接失败 | MinIO 的端口写成了网页控制台的端口；需要打开「路径风格」 |
