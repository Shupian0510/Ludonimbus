# 夸克网盘（实验性）

0.5 起可以一键连接夸克网盘：用夸克 App 扫码登录，剩下的 Ludonimbus 自动完成。

::: info 为什么是「实验性」
夸克没有给第三方应用的官方接口。Ludonimbus 借助开源工具 [OpenList](https://github.com/OpenListTeam/OpenList) 连接夸克，它的夸克驱动用的是夸克网页版的接口，夸克改动接口时可能暂时用不了。即使用不了也不会丢存档：存档还在本机，同步失败会明确提示，可以随时换到其他云盘，并把历史版本复制过去（见[换云盘与复制存档](./switching.md)）。
:::

## 连接

1. 打开「设置 → 云盘」，找到「夸克网盘（实验性）」。中文界面的[首次使用引导](../guide/first-run.md)里，第一个推荐的也是它。
2. 第一次使用要下载 OpenList 组件：点「下载组件并连接」。组件约 57 MB，来自 OpenList 在 GitHub 的官方发布页，下载后会校验 SHA-256。
   - GitHub 下载太慢时，可以先在浏览器里下载 [openlist-windows-amd64.zip](https://github.com/OpenListTeam/OpenList/releases/download/v4.2.10/openlist-windows-amd64.zip)（OpenList v4.2.10 的官方安装包），再点「GitHub 下载太慢？选择已下载的安装包…」选择它。不是这个版本的文件会被拒绝。
3. 弹出「登录夸克网盘」窗口，显示夸克网盘的官方网页。用夸克 App 扫码登录（也可以用网页上的其他登录方式）。
4. 登录后窗口自动关闭，设置页显示「已连接夸克网盘」。

![设置 → 云盘 → 夸克网盘](/screenshots/zh-CN/settings-cloud-quark.png)

![「登录夸克网盘」窗口](/screenshots/zh-CN/quark-login-window.png)

登录过程中可以点「取消」，或者直接关掉登录窗口。

## 存档放在哪里

夸克网盘根目录下的「Ludonimbus」文件夹，网页版和 App 里都能看到。Ludonimbus 只读写这个文件夹，看不到网盘里的其他文件。

## 速度

2026 年 11 月用非会员账号实测：

| 操作 | 耗时 |
|---|---|
| 从 Steam 启动游戏前检查云端 | 约 1 到 2 秒 |
| 上传一个 1 MB 的存档版本 | 约 12 秒 |
| 下载一个 1 MB 的存档版本 | 约 2 秒 |

比其他云盘慢一些，不过上传发生在退出游戏之后，不耽误玩。每个游戏第一次上传会多等约 10 秒（要先建文件夹）。

## 登录失效

夸克的登录过期后，侧边栏显示「云盘需要重新连接」，设置页的提示是「夸克网盘登录已失效」。点「重新扫码登录」再扫一次即可，不用重新下载组件，存档也不受影响。

## OpenList 组件是什么

- OpenList 是开源（AGPL-3.0）的网盘挂载工具。Ludonimbus 不修改、不内置它，只在你同意后下载官方发布版并原样运行。
- 它只监听本机（`127.0.0.1`），管理员密码随机生成；同步时用的是一个只能访问「Ludonimbus」文件夹的账号。两个密码都保存在 Windows 凭据管理器里。
- 夸克的登录信息只保存在 OpenList 的数据文件夹 `%APPDATA%\Ludonimbus\openlist\data` 里，Ludonimbus 自己不保存。登录窗口是无痕的，关掉后不留下任何登录状态。
- 只在用夸克时运行：Ludonimbus 打开时它跟着运行，退出时一起退出；不开 Ludonimbus、直接从 Steam 启动游戏时，会临时启动，同步完就停。运行时约占 70 MB 内存。
- 存档只在你的电脑和夸克之间传输，不经过任何第三方服务器。

## 断开

在「设置 → 云盘」点「断开」：停止 OpenList，并删除它的数据文件夹（里面有夸克的登录信息）。组件程序保留，下次连接不用重新下载。夸克网盘里的存档不会被删除。

## 已经在用自己的 OpenList？

也可以继续用你自己运行的 OpenList，按 WebDAV 连接，见 [WebDAV → OpenList / AList](./webdav.md#openlist)。两种方式不要同时用在同一个文件夹上。
