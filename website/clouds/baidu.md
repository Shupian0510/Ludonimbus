# 百度网盘（审核中）

::: info 现状
百度网盘一键登录已经开发完成，**正在等待百度网盘开放平台审核**，通过后会在新版本中开放。在此之前，正式版的设置页里不会出现百度网盘这一项。
:::

## 怎么连接

1. 打开「设置 → 云盘」，在「百度网盘」一项点「连接百度网盘」。
2. Ludonimbus 会在浏览器里打开百度的官方授权页面，同时显示一个授权码和二维码。
3. 在百度的页面上登录百度账号（或用百度网盘 App 扫码），查看要授予的权限，点确认。
4. 授权完成后 Ludonimbus 会自动继续，设置页显示你的网盘昵称和空间用量。

百度账号和密码只在百度的页面上输入，Ludonimbus 看不到也不保存。授权凭据保存在本机的 Windows 凭据管理器里。

## 访问哪些内容

- Ludonimbus 通过百度网盘开放平台的官方接口接入，申请的权限是 `basic` 和 `netdisk`。
- **只读写你网盘里的「我的应用数据/Ludonimbus」文件夹**，存档、版本信息、设备信息等都放在这里，网页版和 App 里都能看到。网盘里的其他文件不会被列出、读取、修改或删除。
- 百度网盘开放平台在服务端也限制应用只能访问自己的目录。

详细说明见[隐私政策 · 百度网盘](../privacy.md#baidu)。

## 删除和恢复

- 在游戏的「版本历史」里删除一个版本，它会移到列表下方的「最近删除」，**30 天内可以恢复**，到期后自动彻底删除。也可以在「最近删除」里手动「彻底删除」。
- 恢复的自动版本会同时被锁定，避免马上又被自动清理删掉。
- 不想保留任何数据时，直接在百度网盘里删除「我的应用数据/Ludonimbus」文件夹。

## 如何解除授权 {#revoke}

1. **在 Ludonimbus 里**：「设置 → 云盘」点「断开」，会删除这台电脑上保存的百度授权凭据。
2. **在百度一侧**：登录百度账号，打开「账号设置 → 授权管理」（[passport.baidu.com/v6/appAuthority](https://passport.baidu.com/v6/appAuthority)），找到 Ludonimbus，点「取消授权」。取消后所有电脑上的 Ludonimbus 授权都会失效。

设置页百度网盘一项里的「如何解除授权？」也有这两步，并能直接打开百度的授权管理页面。解除授权不会删除网盘里的存档。

## 使用自己的百度应用（高级）

在设置里点「使用自己的百度应用（高级）」，可以填写你自己在[百度网盘开放平台](https://pan.baidu.com/union)创建的应用的 AppKey、SecretKey 和应用名称，存档会放在「我的应用数据/你的应用名称」里。SecretKey 只保存在本机的 Windows 凭据管理器里，不写进配置文件，只在登录和刷新授权时发给百度。

## 速度

百度网盘对非会员的下载有限速，拉取较大的存档（或[游戏本体备份](../features/game-backup.md)）时要多等一会儿。

## 关于 OpenList / AList

Ludonimbus 不会通过 OpenList、AList 或其他第三方工具接入百度网盘；百度网盘只通过百度网盘开放平台的官方接口接入。Ludonimbus 本身不提供网盘聚合或挂载能力，[WebDAV](./webdav.md) 连接到哪个服务器完全由你自主配置。
