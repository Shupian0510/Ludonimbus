# 本地 / 同步文件夹

把任意一个文件夹当作「云端」：Ludonimbus 把版本存进去，至于它怎么到达其他电脑，交给这个文件夹本身。

适合：

- **OneDrive、Dropbox、Google Drive 电脑版**等同步客户端的文件夹：由客户端负责上传到云端、同步到其他电脑。
- **NAS 共享目录**：例如映射成网络驱动器的共享文件夹，家里的几台电脑都能访问。
- **移动硬盘**：只是想多留一份备份和版本历史。

## 连接

1. 打开「设置 → 云盘」，在「本地 / 同步文件夹」那一项点「选择文件夹…」。
2. 选一个文件夹，例如 `D:\OneDrive\Ludonimbus`。

## 注意

- **多台电脑同步时，这个文件夹本身要能在电脑之间同步或共享**。只存在一台电脑上的普通文件夹，其他电脑是看不到的。
- 用同步客户端时，换到另一台电脑玩之前，先等客户端同步完成，Ludonimbus 才能看到最新的版本。
- 每个版本都是一个新文件，写好后不会再修改，所以同步客户端一般不会产生冲突副本。
- 文件夹暂时打不开时（例如 NAS 关机、移动硬盘没插），Ludonimbus 会当作云端暂时无法访问：游戏照常启动，存档先留在本机，之后补传。见[离线游玩](../sync/offline.md)。
