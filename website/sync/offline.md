# 离线游玩

连不上云端时（没网、NAS 关机、OpenList 没运行……），游戏照常能玩。

## 启动前连不上云端

从 Steam 启动时，Ludonimbus 会等一小会儿（「设置 → 本机与同步 → 网络超时」，默认 **8 秒**），还连不上就直接启动游戏，不会一直卡着。

如果启动前的同步出了错（不是单纯连不上），会提示「启动前同步存档失败」并显示原因，问你是否仍然启动游戏；选择启动的话，退出游戏后会再尝试上传。

## 离线时的存档

游戏退出后，新的存档先作为版本保存在本机，游戏详情页会显示「有 N 个版本等待上传（云端恢复访问后自动上传）」。

云端恢复访问后会自动补传：下次从 Steam 启动前（来源「启动前补传」），或者托盘里的 Ludonimbus 定期检查时。也可以手动点「立即同步」。

## 状态提示

- 游戏库里显示「云端离线」。
- Steam 游戏页显示「云端暂时无法访问」或「云端无法访问，N 个版本待上传」。
- 左侧栏显示「云盘需要重新连接」时，不是网络问题，而是登录过期或密码改了：到「设置 → 云盘」重新连接。

## 两台电脑都离线玩过

两边都有对方没有的新存档，联网后同步时会出现[存档冲突](./conflicts.md)，选一份就好，另一份留在版本历史里。
