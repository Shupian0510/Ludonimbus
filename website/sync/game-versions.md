# 同一个游戏的几个版本

同一个游戏你可能有好几个版本：Steam 版和 Xbox 应用的版本、PC 版和模拟器里的版本、两台电脑上各装了一份。Ludonimbus 把它们放在**一张游戏卡**里，存档格式相同的版本**自动共用同一个进度**。

## 游戏卡和版本条

游戏库里一个游戏只有一张卡。封面下面一行是它有存档的平台的标志：这台电脑上没有的变灰。

点开游戏，标题下面是**版本条**：每个圈是一个进度，圈里列着共用这个进度的「平台 · 设备」。连在一个圈里的共用同一个进度，分开的各存各的。

点「本机」可以改这台设备的版本怎么存：

| 菜单项 | 做什么 |
|---|---|
| 和其他设备共用 / 这台设备独立 / 跟随「×××」 | 见[多台设备](./devices.md#independent) |
| 自动同步 / 手动 | 启动和退出游戏时要不要自动同步。Steam 装的游戏多一项「只备份」，见 [Steam 装的游戏](../steam/steam-cloud.md) |
| 改存档位置… | 打开「设置」页签改存档位置 |
| 和其他版本分开存 | 这个版本回到自己的进度，不再和别的版本共用 |
| 拆成单独的游戏 | 从这张卡里拆出去，成为另一张卡 |

两张卡其实是同一个游戏时，在版本条上点「关联其他版本…」把它们并成一张。

## 什么时候自动共用

添加一个游戏时，Ludonimbus 先认出它是哪个游戏，再看云端有没有这个游戏、存档格式相同的进度：

- **直接共用，不问**：同一个平台的同一个游戏装在几台设备上；同一个 Switch 游戏在本机和各个模拟器里；存档位置写法相同的 PC 版。
- **问一次**：是同一个游戏，但存档放在不同的地方，例如另一个商店的版本。
- **各存各的**：存档格式不同的版本（例如 PC 版和主机版，没有规则说它们通用）。它们还在同一张卡里，各有各的进度，可以用[「发到…」](#send)手动搬。

只是名字相同、认不出是同一个游戏的，不会合并。

## 「共用进度？」 {#ask-once}

需要问的时候，版本条下面出现一行：

> 和 ××× 上的版本是同一份存档。共用进度？　[共用] [不是]

旁边的「?」里写着对上了几个文件、哪些文件夹对应哪些文件夹。

- **共用**：这个版本加入那个进度。两边的存档内容相同就直接算已同步；这台设备的是旧的就取最新的；两边都有各自的进度，就像[存档冲突](./conflicts.md)一样让你选留哪一份，没选的那份留在「存档」里。
- **不是**：不再提示，各存各的。

一台设备上确认过以后，其他设备上同样的版本直接照着加入，不再问。

本机还没有存档时不会问：先在这个版本里玩一次、存一次档。

反悔：版本条的「本机」菜单里点「和其他版本分开存」。

## Xbox 应用的版本（实验性） {#xbox}

Xbox 应用（Game Pass）装的游戏把存档放在一组「容器」文件里，文件名和 Steam 版不一样。Ludonimbus 能把容器里的存档还原成普通文件，所以它可以和 Steam 版共用进度：

- **在 Xbox 版玩完**：上传的是还原出来的文件，其他设备上的 Steam 版照常自动取到。
- **写进 Xbox 版是实验性的，不会自己发生**。云端有更新的进度时，Xbox 版显示「云端较新」，但不会自动写入；要你自己点「设为当前」或者在冲突里选「使用云端存档」才写，写之前会提示，并且先保留这里现在的存档。
- 写之前关掉游戏和 Xbox 应用。写完以后先断网进一次游戏、存一次档，再联网；Xbox 问保留哪一份时，选这台电脑上的。Xbox 自己的云同步可能把存档换回去。

## 发到… {#send}

存档格式不同的两个版本之间不能共用，但可以手动搬一次：在「存档」页签里某一行的「更多 → 发到…」，选本机的另一个版本。

对话框里会说明这一次怎么写：

- 格式相同：目标的存档换成这一份，和「设为当前」一样。
- 按文件名对应：存档文件放进目标的存档文件夹，同名的覆盖，多的新增，目标里的其他文件不动。
- 游戏在规则列表里（例如星露谷物语的 Switch 版和 PC 版）：按规则只搬存档，不动设置文件。写这份存档的游戏版本比目标的新时会提醒：旧版本的游戏读不了新版本的存档，先更新游戏。
- 两个版本是不同平台、又没有规则：会提醒文件通常不能直接用。

写入前，目标现在的存档会先保留，可以在它的「存档」里设回去。

另一个版本有更新的存档时，游戏页顶部会提示一行，点「发到这个版本…」直接打开这个对话框。
