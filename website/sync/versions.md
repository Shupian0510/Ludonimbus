# 版本历史

每次上传都会在云端留下一个版本。在游戏详情页打开「版本历史」标签，可以看到所有设备上传的版本。

![版本历史](/screenshots/zh-CN/versions.png)

每个版本显示：

- 哪台设备、什么时间保存的（本机上传的会标「（本机）」）；
- 文件数和大小；
- 来源，见下表；
- 标记：「最新」是云端最新的版本，「本机当前」是这台电脑现在的存档对应的版本，「已锁定」是不会被自动清理的版本。

| 来源 | 什么时候产生 |
|---|---|
| 退出游戏后自动 | 从 Steam 启动的游戏退出后上传 |
| 后台检测到退出 | 不经过 Steam 打开的游戏，托盘里的 Ludonimbus 发现它退出后上传 |
| 启动前补传 | 之前没传上去的存档，在下次启动前补传 |
| 手动同步 | 点了「立即同步」 |
| 手动备份 | 点了「备份当前存档」 |
| 恢复旧版本 | 恢复到某个版本之后 |
| 恢复前保护 | 恢复之前，把当时还没上传的存档先备份一份 |
| 冲突时保留 | 冲突时没选的那一份 |

## 恢复

点版本右边的「恢复」，确认后把这个游戏的存档恢复成那个版本。

当前存档如果云端还没有，会先自动备份成「恢复前保护」版本，所以不会丢。恢复错了，再恢复回去就行。游戏运行中不能恢复。

## 在 Steam 里恢复 {#restore-from-steam}

装了 [Steam 插件](../steam/status-in-steam.md) 后，在 Steam 游戏页点「Ludonimbus 云存档」，会弹出同样的版本列表（时间、设备、文件数和大小、备注，以及「最新」「本机当前」「已锁定」标记）。选一个版本点「恢复」并确认，恢复在 Ludonimbus 里进行，Steam 里显示「正在同步…」直到完成。对话框底部还有「立即同步」和「在 Ludonimbus 中打开」。

## 导出 zip

点导出按钮，把这个版本保存成一个 zip 文件，例如想手动拷到别的地方或者分享给别人。

## 备注

点备注按钮，给版本写一句话，例如「打 Boss 前」「二周目开始」。

## 锁定

点锁按钮锁定版本，锁定的版本**永久保留**，不会被自动清理。再点一次解锁。

## 删除

点删除按钮，把这个版本从云端永久删除，无法恢复。锁定的版本和最新版本不能删除。

## 手动备份

在游戏详情页点「备份当前存档」，可以写一句备注。手动备份**永久保留**，不受自动清理影响，适合在关键时刻前留一份。

## 自动清理

自动版本多了会按「设置 → 本机与同步 → 保留最近的自动版本」清理：

- 保留最近的 **20** 个自动版本；
- 另外每天保留 1 个，保留 **30** 天；
- 手动备份和锁定的版本永久保留；最新版本和每台电脑上次同步的版本也不会被清理。

两个数字都可以在设置里改，见[设置项说明](../reference/settings.md)。

## 在云端直接看

每个版本就是云盘里 `Ludonimbus/games/<游戏>/snapshots/` 下的一个 zip，不用 Ludonimbus 也能下载和打开。
