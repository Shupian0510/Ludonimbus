# 存档

每次上传都会在云端留下一份存档。在游戏页打开「存档」页签，能看到这个游戏在所有设备、所有版本上存过的进度。

![「存档」页签](/screenshots/zh-CN/versions.png)

界面上关于存档只有三个词：**当前**、**保留**、**自动存档**。

## 列表里有什么

上半部分只有几行：

- **当前**：这台设备现在用的那一份。
- 每个平台最新的一份：Steam 版、Xbox 版、模拟器……和当前不是同一份时才单独显示。
- **保留**的存档：你点了星标或者起了名字的。
- 别的设备的独立存档里最新的一份，见[多台设备](./devices.md#independent)。

下半部分是折叠起来的「自动存档 N」：每次玩完自动存的那些。

每一行是平台的标志、时间、设备和大小。云端最新的一份标「最新」；这台设备的存档被换掉之前留下的那一份标「替换前」。鼠标停在一行上显示准确的时间和它是怎么来的，见下表。点一行可以看里面有哪些文件。

| 来源 | 什么时候产生 |
|---|---|
| 退出游戏后自动 | 从 Steam 启动的游戏退出后上传 |
| 后台检测到退出 | 不经过 Steam 打开的游戏，托盘里的 Ludonimbus 发现它退出后上传 |
| 启动前补传 | 之前没传上去的存档，在下次启动前补传 |
| 手动同步 | 点了「立即同步」 |
| 手动备份 | 点了「备份当前存档」 |
| 设为当前 | 把某一份设为当前之后 |
| 替换前保留 | 本机的存档被换掉之前，把还没上传的先存一份 |
| 冲突时保留 | 冲突时没选的那一份 |
| 别人分享的 | 导入的 `.lnsave` 文件 |

## 设为当前 {#make-current}

每一行右边的「设为当前」，把这台设备上的存档换成那一份。确认框里写着换成谁在什么时候存的；现在的存档会先保留，不会丢。

换完的提示里有「撤销」。游戏页上也会留一行「……换成了 ××× 的存档」，24 小时内可以撤销，只要这期间没有存过新的进度。

- 游戏运行中不能换。
- 别的平台的存档、别的设备的独立存档，只要格式相同，也是点「设为当前」。格式不同的用「更多 → 发到…」，见[同一个游戏的几个版本](./game-versions.md#send)。
- 换到跟着同一个进度的其他设备上：它们下次同步时自动取到。

## 保留

点一行右边的星标，这份存档就**一直留着**，不会被自动清理。再点一次取消。

「更多 → 改名…」可以给它起个名字，例如「打 Boss 前」「第一年结束」。起了名字的存档也会一直保留。

游戏页上的「备份当前存档」存出来的就是一份保留的存档，可以顺手写一句备注。

## 自动存档会留多少

自动存档按「设置 → 本机与同步 → 自动存档留最近」清理：

- 留最近的 **20** 个；
- 另外每天留 1 个，留 **30** 天；
- 保留的存档一直留着。最新的一份、每个平台最新的一份、每台设备上次同步到的那一份也不会被清理。

两个数字都可以改，见[设置项说明](../reference/settings.md)。

## 删除和最近删除

「更多 → 删除」把一份存档移到列表底部的「最近删除」，**30 天内可以放回**，到期后自动清除；也可以在那里手动「彻底删除」。

保留的存档要先取消保留才能删。最新的一份不能删。

## 导出和导入 {#share}

「更多 → 导出…」把一份存档存成一个 `.lnsave` 文件，可以拷到别处，或者发给朋友。文件里没有你的设备名和文件夹。

朋友在同一个游戏的「存档」页签底部点「导入…」，选这个文件：他那边只是多出一份保留的存档，本机的存档和同步状态都不变，要用的时候点「设为当前」。

Ludonimbus 会先核对这是不是同一个游戏、文件有没有损坏；对不上就不导入，并说明原因。

## 在 Steam 里 {#restore-from-steam}

装了 [Steam 插件](../steam/status-in-steam.md)后，在 Steam 游戏页点「Ludonimbus 云存档」，会弹出同样的列表：时间、设备、文件数和大小，以及「最新」「当前」「保留」标记。选一份点「设为当前」并确认，Steam 里显示「正在切换…」直到完成。对话框底部还有「立即同步」和「在 Ludonimbus 中打开」。

## 存档在云盘里是什么样

一个游戏的所有内容都在云盘的 `Ludonimbus/games/<游戏>/` 下面：`packs/` 里是一个个 zip，装着存档文件本身；`saves/` 里是每一份存档的清单，记着它由哪些文件组成、哪台设备在什么时间存的。

- 存档不超过 16 MB 时（绝大多数游戏），每一份存档就是 `packs/` 里一个完整的 zip，不用 Ludonimbus 也能在云盘的网页上下载和解压。
- 更大的存档只上传变化了的文件，没变的沿用以前的 zip，不会每次整个传一遍。这时要拿到完整的一份，在「存档」页签里导出。

从 0.6 升级上来的游戏，原来 `snapshots/` 里的 zip 都原样留着，照样列在「存档」里。
