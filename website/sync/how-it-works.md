# 同步怎样工作

Ludonimbus 的同步和 Steam 云存档一样：**启动前拉取，退出后上传**。每次上传在云端留下一份存档，写好以后不会再被修改，记着哪台设备、什么时间存的，以及它接在哪一份后面。

原则是**玩游戏不等云盘，除非确实有更新的进度要取**。

## 什么时候同步

| 时机 | 做什么 |
|---|---|
| 从 Steam 启动游戏前 | 云端有更新的存档就拉取下来；有没上传的先补传 |
| 游戏和启动器退出后 | 存档有改动就上传一份 |
| 不经过 Steam 直接打开游戏 | Ludonimbus 在托盘里时，发现游戏退出就自动上传 |
| 在 Steam 里点「停止」强制结束 | 托盘里的 Ludonimbus 会发现并立即补传 |
| 点「立即同步」 | 在游戏页、或者 Steam 游戏页的同步按钮 |
| 后台 | 托盘里的 Ludonimbus 定期检查云端、补传没传完的存档，游戏库里的状态随之更新 |

同一个游戏同一时间只有一个同步在进行：界面、托盘里的后台监视、从 Steam 启动时的小程序和 Steam 里的同步按钮互相排队。

## 要等多久 {#waiting}

**启动前**最多等云端 **10 秒**（「设置 → 本机与同步 → 启动前等云端」）：

- 云端没有更新的存档：通常一次请求就知道，马上启动。
- 到时间云端还没回应：直接启动游戏，这一次改在退出后同步。
- 到时间正在下载更新的存档：继续下载，同时弹出一个小窗口，写着要下载多大，可以点「先玩本机的」。选了的话两份都会留着，之后问你用哪一份。

**退出后**最多等上传 **10 秒**（「退出后等上传」）：传完就结束；传不完就转到后台继续，Steam 里游戏显示为已停止，不用等着。打开「一直等到传完」则会等到上传结束，适合玩完马上关机或休眠的设备。

没传完就关机也不要紧：存档已经在本机排着队，下次开机后继续传。传到一半断了，不会在云端留下半份存档。

## 怎么判断该做什么

每一份存档都记着「它包含了每台设备到第几次为止的修改」。Ludonimbus 靠这个判断谁新谁旧，**不看电脑的时钟**：两台电脑的时间不准、时区不同都没有关系。

| 本机 | 云端 | 结果 |
|---|---|---|
| 没变 | 没有更新的存档 | 什么都不做 |
| 没变 | 有更新的存档 | 拉取（本机的先保留） |
| 变了 | 没有更新的存档 | 上传 |
| 变了 | 有更新的存档 | **冲突**，两份都保留，让你选择。见[存档冲突](./conflicts.md) |
| 没有存档 | 有存档 | 拉取（例如重装了游戏） |
| 新设备，第一次同步 | 有存档 | 内容一样就算已同步，不一样算冲突 |
| 连不上云端 | — | 照常启动，存档排队等以后补传。见[离线游玩](./offline.md) |

没等到的那一次同步（上面的「先启动再说」）最坏也只是一次冲突：会被发现、会问你，不会悄悄覆盖。

除了按规则清理旧的自动存档，Ludonimbus 不会删除任何存档；保留的存档、最新的一份、每台设备上次同步到的那一份都不会被清理。见[存档](./versions.md)。

## 游戏库里的状态

游戏卡封面下面有一个状态点，鼠标停上去显示状态的名字；需要你处理的（冲突、出错）点的后面直接写着。

| 状态 | 意思 |
|---|---|
| 已同步 | 本机和云端一致 |
| 待上传 | 本机有新存档，还没上传 |
| 云端较新 | 其他设备上传了更新的存档，下次启动前会拉取 |
| 可从云端恢复 | 本机没有存档，云端有 |
| 尚未上传 | 本机有存档，云端还没有 |
| 存档冲突 | 本机和云端都有新改动，需要你选择 |
| 云端离线 | 暂时连不上云端 |
| 未连接云盘 | 还没有在设置里连接云盘 |
| 暂无存档 | 本机和云端都还没有存档 |
| 游戏运行中 | 游戏正在运行，退出后同步 |

## 等游戏真正退出

有些游戏先打开一个启动器，启动器再打开游戏本身，或者游戏退出后还要过一会儿才写完存档。Ludonimbus 会：

- 等游戏**和启动器**都退出后再上传；内置规则里写了游戏真正的进程名，启动器先退出也能认出游戏还在运行。
- 有的游戏在写存档时会留一个锁文件，等它被释放（最多 20 秒）。
- 启动器一直开着的游戏，可以设成「游戏进程退出就上传」，见 [Steam 自动同步](../steam/auto-sync.md#launcher)。

## 写进游戏的时候

把一份存档写进游戏的存档文件夹（拉取、设为当前）是整体完成的：每个文件先写在旁边、核对无误，全部对了才换上去。中途出错或断电，存档要么是新的那一份，要么和之前一样，不会是半份。

换之前，本机还没上传的存档会先保留一份；换错了可以[撤销](./versions.md#make-current)。

## 同一个游戏的几个版本

Steam 版、Xbox 版、模拟器里的版本，存档格式相同的会自动共用同一个进度，见[同一个游戏的几个版本](./game-versions.md)。Steam 商店装的游戏见 [Steam 装的游戏](../steam/steam-cloud.md)。

存档怎么查看、保留和清理，见[存档](./versions.md)。
