# 多台设备

在几台电脑（台式机、笔记本、掌机）之间接着玩：每台电脑都装 Ludonimbus，连接同一个云盘就行。

## 设置第二台电脑

1. 安装 Ludonimbus。
2. 在「设置 → 云盘」连接**同一个**云盘：同一个 Google 账号，或者同一个 WebDAV / S3 服务器和文件夹，或者同一个同步文件夹。
3. 在「设置 → 本机与同步 → 设备名称」给这台电脑起个认得出的名字，例如「客厅主机」「掌机」。版本历史和冲突提示里会显示这个名字。
4. 添加游戏，见下一节。
5. 开启 Steam 自动同步，或者一键加入 Steam。

## 把云端的游戏加到这台电脑

**办法一：「云端已有」**（最稳妥）

「添加游戏 → 云端已有」会列出其他电脑上传过、但这台电脑还没添加的游戏。点「关联到本机…」，选这台电脑上对应的 Steam 快捷方式；不在 Steam 里的，点「不在 Steam 里，直接选择游戏程序…」。关联后同步一次，就会把云端存档拉下来。

<!-- screenshot: add-game-cloud -->

**办法二：直接扫描**

用「扫描本机」添加时，被内置规则认出的游戏、和其他电脑上同名的游戏会用同一个游戏 id，自动对上云端已有的存档。

每个游戏的 id 显示在游戏详情页「设置」标签的最下面：「游戏 id：……（多台设备靠它找到同一份云端存档）」。两台电脑上 id 一样，才是同一份存档。

## 设备页

左侧栏的「设备」列出连接到同一个云盘的电脑：设备名、最后在线时间、Ludonimbus 版本和系统。每个版本都会记录是哪台设备上传的。

## 换着玩的时候

- 一台电脑上玩完，让游戏正常退出、上传完成，再到另一台电脑上从 Steam 启动，它会先拉取最新的存档。
- 两台电脑都改过存档时会[冲突](./conflicts.md)，两份都会保留。

## 模拟器在不同电脑上

- 模拟器装在不同的文件夹没关系，存档按模拟器的数据目录记录。
- **Switch 模拟器**：Ryujinx 按游戏同步，每台电脑会找到当前用户档案的存档，没有就自动新建（需要先关闭 Ryujinx）。Eden、Citron、Sudachi、Suyu、yuzu 只能整个模拟器一起同步（连同用户档案）。见[模拟器](../supported/emulators.md)。
