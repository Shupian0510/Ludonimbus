# 多台设备

在几台设备（台式机、笔记本、掌机）之间接着玩：每台都装 Ludonimbus，连接同一个云盘就行。

## 设置第二台设备

1. 安装 Ludonimbus。
2. 在「设置 → 云盘」连接**同一个**云盘：同一个 Google 账号，或者同一个 WebDAV / S3 服务器和文件夹，或者同一个同步文件夹。
3. 在「设置 → 本机与同步 → 设备名称」给这台设备起个认得出的名字，例如「客厅主机」「掌机」。存档列表和冲突提示里会显示这个名字。
4. 添加游戏，见下一节。
5. 开启 Steam 自动同步，或者一键加入 Steam。

## 把云端的游戏加到这台设备

其他设备上传过、这台设备还没有的游戏，在游戏库里是灰色的「只在云端」卡片，点开就能看它的存档和游戏时间。

**办法一：直接扫描**

用「添加游戏 → 扫描本机」添加。Ludonimbus 认出这是云端已有的同一个游戏，就自动接上那份进度：同一个平台的同一个游戏不用问；存档放在不同位置的版本会问一次，见[同一个游戏的几个版本](./game-versions.md)。

**办法二：「云端已有」**

「添加游戏 → 云端已有」列出其他设备上传过、但这台设备还没添加的游戏。点「关联到本机…」，选这台设备上对应的 Steam 快捷方式；不在 Steam 里的，点「不在 Steam 里，直接选择游戏程序…」。在「只在云端」的游戏页里点「添加到本机…」是一样的。

![添加游戏 → 云端已有](/screenshots/zh-CN/add-game-cloud.png)

添加后同步一次，就会把云端的存档拉下来。本机已经有不一样的存档时，会让你选留哪一份，另一份留在[「存档」](./versions.md)里。

## 换着玩的时候

- 一台设备上玩完，让游戏正常退出、上传完成，再到另一台上从 Steam 启动，它会先拉取最新的存档。
- 两台设备都改过存档时会[冲突](./conflicts.md)，两份都会保留。

## 这台设备存自己的进度 {#independent}

默认所有设备共用同一个进度。想让某台设备各玩各的（例如孩子的电脑、借给朋友的掌机），在游戏页的版本条上点「本机」：

| 选项 | 意思 |
|---|---|
| 和其他设备共用 | 默认 |
| 这台设备独立 | 这台设备存自己的进度，不取别人的，也不改别人的 |
| 跟随「×××」 | 和另一台独立的设备共用它的进度。例如爸爸的台式机和掌机共用，孩子的电脑独立 |

- 改成独立不会丢东西：这台设备接着现在的存档往下存，共用的进度原样留着。
- 改回共用时，本机的存档和共用的最新进度不一样，会让你选留哪一份。
- 独立的进度在其他设备的「存档」页签里也看得到（最新的一份），可以点「设为当前」拿过来。
- 游戏时间和成就本来就是每台设备各记各的。

想让这台设备上以后新添加的游戏都独立：打开「设置 → 本机与同步 → 新游戏独立存档」。已经在同步的游戏不变。

## 设备页

左侧栏的「设备」列出连接到同一个云盘的设备：设备名、最后在线时间、Ludonimbus 版本和系统。

还在用旧版本 Ludonimbus 的设备会标「需要更新」，见下一节。

## 从 0.6 升级到 1.0 {#upgrade}

1.0 换了云端存放存档的方式。升级不需要你做什么：

- 第一台升级的设备会在后台把云端整理一次。**原来的文件一个都不动、不搬、不删**；云盘慢的话可能要几分钟，这期间游戏照常能玩，存档排队等整理完再传。
- 游戏、存档和游戏时间都会带过来。原来「锁定」的和「手动备份」的版本成为[保留的存档](./versions.md)，备注成为它的名字。
- **其他设备也尽快更新。** 还在 0.6 的设备看不到 1.0 存的存档；这时在它上面玩同一个游戏，更新了的设备会发现它上传的存档，并像[冲突](./conflicts.md)一样让你选。
- 本机的设置在 1.0 第一次改动它之前，会另存一份 `config.v1.json`（在数据目录里）。

## 模拟器在不同设备上

- 模拟器装在不同的文件夹没关系，存档按模拟器的数据目录记录。
- **Switch 模拟器**：Ryujinx 按游戏同步，每台设备会找到当前用户档案的存档，没有就自动新建（需要先关闭 Ryujinx）。Eden、Citron、Sudachi、Suyu、yuzu 只能整个模拟器一起同步（连同用户档案）。见[模拟器](../supported/emulators.md)。
