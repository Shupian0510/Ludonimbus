# Game sources and groups

The library recognises where each game comes from: an emulator (shown by its name), recomps & ports, PC games, Xbox or other. The categories at the top of the library filter by source, and the list view shows each game's source under its name.

The logos next to categories and groups are the emulators', recomps' and the Xbox app's own icons, read from the programs installed on this PC; when a program isn't on this PC, only its name is shown.

![The library filtered and grouped by source](/screenshots/en/library-sources.png)

- **Filter**: click "All", "Dolphin", "Recomps & ports", "PC games"… at the top to see only those; the number is how many games there are.
- **View options**: "Group by source" splits the library into groups; turn off "Show categories" to hide the categories at the top (this also clears the filter).
- **Whole groups**: when grouped, each group's heading has "Sync all" and "Back up all". Back up all makes a manual backup of each game, kept forever, with an optional note such as "before updating the emulator". Games that are running or have no saves are skipped.

## Choose the group yourself

Sources are detected automatically. To group differently, enter a "Source group" in the game page's Settings tab, such as an emulator's name to keep its games together; leave it empty to detect it automatically.

The name only changes how the library groups games. Which rules saves, game backups and achievements use still depends on the emulator or game Ludonimbus recognised.
