# Scan folder

Games that weren't installed through Steam, Epic, GOG or Xbox (portable games, emulators kept in `D:\Games` and so on) aren't found by "Scan this PC" by default. Let Ludonimbus scan the folder where you keep them.

1. In "Add game → Scan this PC", click "Scan folder…".
2. Pick the folder with your games, for example `D:\Games`.
3. Ludonimbus reports how many games it found in that folder. They join the list (source "Folder") and are grouped like the rest.

![Add game → Scan folder](/screenshots/en/add-game-scan-folder.png)

If the folder contains emulators, the games with saves inside them are listed one by one too.

From here it's the same as [Scan this PC](./scan.md): tick the ones that are ready to add, and click "Choose saves…" for the ones that need a save location.

If a game program isn't found, pick it directly with [Add manually](./manual.md).
