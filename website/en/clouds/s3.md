# S3-compatible storage

Many object stores speak the Amazon S3 API: Cloudflare R2, Aliyun OSS, Tencent COS, and MinIO, which you can run on a NAS. Saves are small, so pay-as-you-go storage costs very little.

## Steps

1. In your provider's console, **create a bucket** and an access key pair (access key and secret key). Ludonimbus doesn't create buckets.
2. Open Settings → Cloud and click "Enter S3 details…".
3. Under "Presets", click your provider (MinIO (NAS), Aliyun OSS, Tencent COS, Cloudflare R2). Ludonimbus fills in the endpoint format and shows notes.
4. Fill in:
   - **Endpoint**: the service address; replace the parts in angle brackets `<…>`.
   - **Region**: can be left empty (defaults to `us-east-1`).
   - **Bucket**: the bucket from step 1.
   - **Path prefix**: where saves go inside the bucket, `Ludonimbus` by default.
   - **Access key** and **Secret key**.
   - **Path style**: address the bucket as endpoint/bucket; MinIO and similar servers need it.
5. Click "Test connection", then "Connect".

The secret key is kept in the Windows Credential Manager and removed when you disconnect.

::: tip Use a key with the least access
Create a separate sub-account or token for Ludonimbus that can only access this bucket, instead of your main account's keys.
:::

## MinIO (NAS) {#minio}

| Field | Value |
|---|---|
| Endpoint | `http://<NAS address>:9000` (MinIO's API port, not the web console's port) |
| Region | Empty |
| Path style | **On** |

Create the bucket and the access key in the MinIO console.

## Aliyun OSS {#aliyun-oss}

| Field | Value |
|---|---|
| Endpoint | The endpoint of the bucket's region, for example `https://oss-cn-hangzhou.aliyuncs.com` for Hangzhou |
| Path style | Off |

Use the AccessKey of a RAM user that can only access this bucket.

## Tencent COS {#tencent-cos}

| Field | Value |
|---|---|
| Endpoint | The endpoint of the bucket's region, for example `https://cos.ap-guangzhou.myqcloud.com` for Guangzhou |
| Region | Matches the endpoint, for example `ap-guangzhou` |
| Bucket | **Include the `-APPID` suffix**, for example `ludonimbus-1250000000` |
| Path style | Off |

Create keys under Cloud Access Management → API Key Management, preferably for a sub-user.

## Cloudflare R2 {#cloudflare-r2}

| Field | Value |
|---|---|
| Endpoint | `https://<account ID>.r2.cloudflarestorage.com` |
| Region | `auto` |
| Path style | Off |

Create an R2 API token with object read & write permission to get an access key ID and secret access key.

## Can't connect? {#troubleshooting}

| What you see | Likely cause |
|---|---|
| Bucket doesn't exist | Wrong bucket name; the `-APPID` suffix is missing (Tencent COS); the endpoint is in a different region |
| Signature error / access denied | Wrong secret key; the region doesn't match the endpoint; the key has no access to this bucket |
| Connection failed | MinIO's web console port was used instead of the API port; "Path style" needs to be on |
