# 收藏

左侧栏的「收藏」是你的游戏一共玩了多少，加上两个书架：玩通了的，和收起来的。

![收藏](/screenshots/zh-CN/collection.png)

## 上面的三个数

- **总时长**：所有游戏在所有设备上的游戏时间加起来，见[游戏时间](./playtime.md)。
- **游戏**：一共几个游戏。同一个游戏的几个版本算一个。
- **成就**：解锁了多少。只算这台电脑认得出成就的游戏，「?」里是具体的个数，见[成就](./achievements.md)。

## 已通关

在游戏页点「…」，选「标为已通关」，游戏就放上这个书架；再点一次「取消已通关」拿下来。游戏页的状态里会多一个「已通关」标记。

## 已归档

通关以后不打算再玩、想把游戏卸载掉，又想留着它的存档、游戏时间和成就：在游戏页点「…」，选「归档」。

- 归档的游戏不再出现在游戏库里，只在「收藏」的这个书架上；游戏库最下面有一行「已归档 N 个」，点一下就到这里。
- 存档、游戏时间和成就都在云端，归档不会删除任何东西。本机的游戏可以放心卸载。
- 想再玩的时候，在收藏里点开它，选「取消归档」，它就回到游戏库。重新装好游戏以后，像[多台设备](../sync/devices.md)里说的那样添加到本机，存档会拉下来。

## 所有设备上都一样

书架记在云端这个游戏的记录里，所以在一台设备上标的，其他设备上也看得到。同一个游戏的几个版本（Steam 版、模拟器版……）一起上架、一起拿下。

游戏还没上传过存档时，云端没有它的记录，放不上书架；先同步一次。
