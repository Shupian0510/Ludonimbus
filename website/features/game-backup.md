# 游戏本体备份

除了存档，还可以把游戏本身备份到你的云盘。游戏删了、硬盘坏了或者换了电脑，在 Ludonimbus 或 Steam 游戏页就能装回来，存档自动拉取。

![游戏详情页的「游戏本体」卡片](/screenshots/zh-CN/game-files.png)

## 备份什么

游戏详情页的「游戏本体」卡片。备份的是游戏文件夹，**不含存档、日志和缓存**（存档另外同步）。

模拟器和重编译游戏会分成几部分备份：

| 部分 | 内容 |
|---|---|
| 程序 | 模拟器或重编译程序 |
| 游戏文件 | 光盘镜像、ROM、游戏文件夹、更新、DLC |
| 设置和 mods | 这个游戏的设置、图形包、mods |
| 密钥和固件 | 只在「备份设置」里勾选「也备份密钥、固件、BIOS」时备份（Cemu、Ryujinx、Dolphin、shadPS4、RPCS3） |

- 几个游戏共用同一个模拟器时，模拟器只上传一次。
- 重编译游戏的启动器自己会编译的东西不备份，恢复后启动器会重新编译。个别游戏（例如 fefw recomp）需要恢复后自己运行一次启动器来编译。
- 「计算大小」先列出每部分的文件数和大小，不上传。「备份设置」里可以取消某一部分。

## 备份和更新

- 点「备份到云端」：依次扫描、查看云端、上传（显示速度和剩余时间）、核对、保存版本。中途可以「停止」，下次备份时已经传过的不再传。
- 之后点「更新备份」：游戏文件按内容切成小块，**只上传改动的部分**；没变化时提示「游戏文件没有变化」。
- 每次备份是一个版本。默认保留最近 2 个，新备份成功后自动删掉更旧的，可以在「备份设置」里改。各版本相同的内容只存一份。

## 恢复和从云端安装

- 点「恢复…」：对话框列出这个版本有哪些部分。「程序」可以用本机已经有的模拟器，或者恢复备份里的；「装到」和「游戏文件放到」选位置。
- 本机没有游戏文件时，卡片显示「本机没有文件」和「从云端安装…」。
- 勾选「恢复后让 Ludonimbus 和 Steam 快捷方式指向新位置，并拉取云存档」时，会自动修正游戏位置和启动参数，并拉取存档。
- 恢复中途停止的，卡片上有「继续恢复」，从断点接着来。已经在本机、内容一样的文件不会改动。

## 在 Steam 里

装了 [Steam 插件](../steam/status-in-steam.md) 后，游戏文件不在本机时，Steam 游戏页的 Ludonimbus 状态显示「本机没有游戏文件 · 点击从云端安装」。点击打开 Ludonimbus 的恢复对话框，安装时 Steam 里显示进度。

## 云盘和速度

- 备份放在云盘的 `Ludonimbus/gamebackup/` 下，只是你自己的备份，不提供分享。
- 游戏动辄几十 GB，注意云盘空间。Google Drive 单个账号每天最多上传约 750 GB。
- 百度网盘没有会员时下载很慢（约 80 KB/s），恢复会很久，备份前会提示。
- 「设置 → 云盘测速」可以测当前云盘的上传和下载速度，测完自动删除测试文件。
