# 设置项说明

## 设置页 {#app}

左侧栏点「设置」。

![设置](/screenshots/zh-CN/settings.png)

### 云盘

连接、切换或断开云盘，见[怎么选云盘](../clouds/index.md)。连接后显示云盘类型、账号或地址，以及已用空间（云盘支持时）。云盘出问题时会显示「需要处理」和原因。

### 语言 / Language {#language}

界面语言：「跟随系统」「简体中文」或「English」，改了立刻生效。默认跟随 Windows 的显示语言（中文系统用中文，其他用英文）。托盘菜单、从 Steam 启动时的弹窗和 [Steam 里的云存档状态](../steam/status-in-steam.md)也用这个语言。

![设置 → 语言](/screenshots/zh-CN/settings-language.png)

### 本机与同步

| 设置 | 默认 | 说明 |
|---|---|---|
| 设备名称 | 电脑名 | 存档列表、冲突提示和设备页里显示的名字。有几台设备时建议改成认得出的名字 |
| 自动存档留最近 | 20 个，另外每天 1 个，留 30 天 | 超出的自动存档会被清理。保留的存档一直留着，见[存档](../sync/versions.md) |
| 网络超时 | 8 秒 | 连一次云端最多等这么久 |
| 启动前等云端 | 10 秒 | 启动游戏前最多等云端这么久。到时间还没好，就先启动游戏，这一次改在退出后同步；正在下载更新的存档时会等它下完（可以选「先玩本机的」） |
| 退出后等上传 | 10 秒 | 游戏退出后最多等上传这么久。超过以后上传转到后台继续，Steam 里游戏显示为已停止 |
| 一直等到传完 | 关 | 打开后，退出游戏时一直等到上传结束。适合玩完马上关机或休眠的设备 |
| 新游戏独立存档 | 关 | 打开后，这台设备上新添加的游戏各存各的，不和其他设备共用进度。已经在同步的游戏不变；每个游戏可以在游戏页单独改，见[多台设备](../sync/devices.md#independent) |

等待时间的说明见[同步怎样工作](../sync/how-it-works.md#waiting)。两个开关改了立刻生效，其余的改完点「保存」。

### Steam

| 设置 | 说明 |
|---|---|
| Steam 位置 | Ludonimbus 用的 Steam 文件夹，默认自动检测。装了多个 Steam 或没检测到时：「快速扫描」在注册表和各个磁盘的常见位置找，找到多个时点一个使用；「重新选择…」自己选 Steam 的安装文件夹（里面有 `steam.exe`）。手动指定后可以点「恢复自动检测」 |
| Steam 账号 | 有多个 Steam 账号时，选 Ludonimbus 读取和修改哪个账号的快捷方式 |
| Steam 装的游戏 | 几个已加入、几个还没加入。「全部只备份」把还没加入的都加进来；「更多 → 全部接管…」把只备份的都改成由 Ludonimbus 同步。见 [Steam 装的游戏](../steam/steam-cloud.md) |
| 截图同步 | 不同步（默认）/ 只上传本机的截图 / 上传，并下载其他电脑的截图，见[截图同步](../features/screenshots.md) |
| 启动包装器 | `ludonimbus-run.exe` 的位置。显示「找不到 ludonimbus-run.exe」时 Steam 自动同步无法使用，请重新安装 Ludonimbus |

### 在 Steam 中显示云存档状态

安装、启用或移除 Steam 插件，并显示 Millennium 和插件的状态。见[在 Steam 里显示云存档状态](../steam/status-in-steam.md)。

### 成就 {#achievements}

| 设置 | 说明 |
|---|---|
| 新关联的游戏默认弹出 Steam 成就提醒 | 每个游戏还可以在自己的「成就」标签里单独开关 |
| Steam 弹不出来时，用 Ludonimbus 自己的小窗口提醒 | 小窗口只在窗口化或无边框全屏的游戏上面看得见 |
| 测试弹窗 / 8 秒后测试 | 发一个测试成就，看提醒能不能弹出来 |
| PS4 奖杯密钥 | 读取 PS4 奖杯的官方名称需要的密钥，只保存在本机；shadPS4 里已经填了时自动使用，见[成就](../features/achievements.md#ps4-trophy-key) |
| RetroAchievements 账号 | 用户名和 Web API Key（在 RetroAchievements 网站「设置 → Keys」复制），Key 保存在 Windows 凭据管理器里 |

### 云盘测速 {#speed-test}

测当前云盘的上传和下载速度，测完自动删除测试文件。用来估计[游戏本体备份](../features/game-backup.md)要多久。

### 封面（SteamGridDB）

填写或删除 SteamGridDB API Key。见[封面与 SteamGridDB](../steam/artwork.md)。

### 关于

| 项目 | 说明 |
|---|---|
| 版本 | 当前版本，「检查更新」手动检查新版本 |
| 数据目录 | `%APPDATA%\Ludonimbus`：设置、同步记录、日志都在这里，点一下打开 |
| Ludusavi | 附带的 Ludusavi 程序位置；「未找到」只影响从 Ludusavi 数据库添加 PC 游戏 |
| 设备 id | 这台电脑在云端的唯一标识 |
| 链接 | 文档、GitHub、反馈问题，以及「重新打开新手引导」（见[首次使用引导](../guide/first-run.md)） |

## 单个游戏的设置 {#per-game}

在游戏详情页打开「设置」标签。

![游戏详情页：设置](/screenshots/zh-CN/game-settings.png)

| 设置 | 说明 |
|---|---|
| 名称 | 在 Ludonimbus 里显示的名称 |
| 来源分组 | 游戏库按这个名字分组，留空则自动识别，见[游戏来源与分组](../games/sources.md) |
| 自动同步 | 关闭后，启动 / 退出游戏时不再同步，手动操作（立即同步、备份）仍可用。游戏页版本条的「本机」菜单里也能改 |
| 上传时机 | 勾选「游戏进程退出就上传，不等启动器关闭」，适合启动器会一直开着的游戏；需要先填「游戏进程」 |
| 存档位置 | 要同步的文件夹或文件，每行一个。留空则使用内置规则（灰色提示里会显示内置规则用的位置）。「查找存档…」列出名字相近的文件夹，勾选后加进来；「添加文件夹…」自己选 |
| 排除 | 不同步的文件，写法同上。「排除文件夹…」选一个文件夹加进来 |
| 游戏进程 | 游戏真正的进程名，例如 `game.exe`，用来判断游戏是否还在运行。留空则使用内置规则。「选择程序…」选一个程序，把它的文件名加进来 |
| 启动参数 | 启动游戏时附加的参数 |

改完点「保存设置」。最下面显示这台设备上的游戏 id。

这个版本和别的版本共用进度时（见[同一个游戏的几个版本](../sync/game-versions.md)），改了存档位置，原来对上的文件夹就不作数了：它回到自己的进度，新位置对得上的话会再问一次。

「从 Ludonimbus 移除」只会从本机的 Ludonimbus 里移除这个游戏，云端的存档都会保留，以后重新添加就能找回；Ludonimbus 创建的 Steam 快捷方式也会一起删除。

### 存档位置的写法

每行以一个根目录开头，后面接相对路径；`*` 匹配任意文件名，`**` 匹配任意多层文件夹。

| 根目录 | 指向 |
|---|---|
| `{install}` | 游戏目录（游戏程序所在的文件夹） |
| `{appdata}` | `%APPDATA%`（`AppData\Roaming`） |
| `{localappdata}` | `%LOCALAPPDATA%`（`AppData\Local`） |
| `{documents}` | 「文档」文件夹 |
| `{home}` | 用户文件夹 |

例子：

```text
{install}/save/**
{appdata}/MyGame/Saves/**
{documents}/My Games/MyGame/*.sav
```

用 `{install}` 写的位置跟着游戏目录走：游戏换了文件夹、换了电脑，存档也能放回正确的地方。

## 托盘

关闭窗口后 Ludonimbus 会留在系统托盘，负责后台监视不经过 Steam 打开的游戏、给 Steam 插件提供状态。托盘菜单里可以「打开 Ludonimbus」或「退出」。
