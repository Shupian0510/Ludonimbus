# 手动添加

扫描找不到、或者你想自己指定的游戏，用「添加游戏 → 手动添加」。

## 1. 选择游戏程序

点「选择游戏程序…」选游戏的 exe。Ludonimbus 用它判断游戏是否在运行、在游戏目录附近找存档，以后也能一键加入 Steam。

- 下面有各平台安装目录的快捷入口：Steam、Xbox、Epic、GOG、EA、Ubisoft，点一下直接打开对应的文件夹。
- **Xbox 应用（PC Game Pass）的游戏**请选游戏文件夹 `Content` 里的 `gamelaunchhelper.exe`。游戏自己的程序受系统保护，选不了也启动不了。
- **模拟器**请选模拟器程序，会自动套用内置规则。
- 没有程序（例如只想备份某个存档文件夹）：点「没有程序，直接指定存档」。

## 2. 被内置规则认出

选的程序被认出时，会显示「识别为……，会使用内置的存档规则，不用自己找存档」。确认名称后点「添加」就好。

::: tip 模拟器：整个同步还是逐个游戏
直接选模拟器程序时，模拟器里所有游戏的存档会一起同步。想按游戏分开同步，请用「扫描本机」添加模拟器里有存档的游戏，或者在 Steam 里给每个游戏建一个带游戏文件的快捷方式（例如用 Steam ROM Manager），再从「扫描本机」添加。见[模拟器](../supported/emulators.md)。
:::

## 3. 没认出：找存档

没认出的游戏会进入[找存档向导](./save-finder.md)：在 Ludusavi 数据库里找、从常见位置里挑、「玩一下再找」，或者自己选文件夹。

## 从 Ludusavi 数据库添加 {#ludusavi}

「添加游戏」里还有一个「Ludusavi 数据库」标签：输入游戏英文名（例如 Hollow Knight）搜索，点「查看存档」能看到这台电脑上找到的存档文件，再点「添加」。本机还没有存档也可以添加，以后找到存档时会自动同步。这种方式没有游戏程序，需要的话之后在详情页设置游戏位置。

## 添加之后

- 在游戏详情页的「设置」里可以改名称、存档位置、排除的文件、游戏进程和启动参数，见[设置项说明](../reference/settings.md#per-game)。
- 要从 Steam 启动并自动同步：已经在 Steam 里的打开「Steam 自动同步」，不在的点「加入 Steam…」。
