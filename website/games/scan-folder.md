# 扫描文件夹

不是通过 Steam、Epic、GOG、Xbox 装的游戏（例如解压即玩的游戏、放在 `D:\Games` 里的模拟器），「扫描本机」默认找不到它们的程序。可以让 Ludonimbus 扫描你放游戏的文件夹。

1. 「添加游戏 → 扫描本机」，点「扫描文件夹…」。
2. 选放游戏的文件夹，例如 `D:\Games`。
3. Ludonimbus 会提示「在 D:\Games 里找到 N 个游戏」，它们会出现在列表里（来源「文件夹」），和其他游戏一样分组。

<!-- screenshot: add-game-scan-folder -->

扫描到的文件夹里如果有模拟器，模拟器里有存档的游戏也会逐个列出来。

接下来和[扫描本机](./scan.md)一样：能直接添加的勾选添加，需要指定存档的点「指定存档…」。

没有找到游戏程序时，可以用[手动添加](./manual.md)直接选择程序。
