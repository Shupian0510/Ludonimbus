# 找存档向导

Ludonimbus 认不出存档位置的游戏，会打开找存档向导：在「扫描本机」里点「指定存档…」，或者在「手动添加」里选好游戏程序后。

向导里有四种办法，从上往下试，任何一种找到了就可以添加。

<!-- screenshot: save-finder -->

## 1. 在 Ludusavi 数据库里找

Ludusavi 数据库收录了上万款 PC 游戏的存档位置（来自 PCGamingWiki）。输入游戏英文名搜索，选中结果，就不用自己选文件夹了。

## 2. 常见的存档位置

Ludonimbus 会在「文档」「保存的游戏」、AppData 和游戏目录里，找名字和游戏相近的文件夹，最近修改的排在前面。每个候选会显示文件数、大小、修改时间和几个文件名示例，勾选看起来对的那个。

## 3. 玩一下再找

认不出、也猜不到的游戏，用这个办法最可靠：

1. 点「开始记录并启动游戏」（没有游戏程序时是「开始记录」，然后自己打开游戏）。
2. 进游戏玩一会儿，**存一次档**，然后退出游戏。
3. 点「完成」。

Ludonimbus 会列出这段时间里被写入的文件夹（已经排除缓存、日志等），通常第一个就是存档文件夹。没有发现明显的变化时，可以再试一次，确认真的存了档；或者用第 4 种办法。

## 4. 自己选择文件夹

点「选择文件夹…」，直接选存档文件夹。知道存档在哪里时这样最快。

## 选好之后

底部会显示「已选 N 个存档文件夹」或「使用 Ludusavi 数据库：……」，确认名称后点「添加」。

::: warning 别选成整个游戏目录
选中的文件夹超过 200 MB 时会提醒你「可能选到了整个游戏目录」。存档一般只有几 KB 到几十 MB；把整个游戏目录当成存档，每次同步都会上传整个游戏。
:::

以后还可以在游戏详情页的「设置」里修改存档位置和排除的文件，见[设置项说明](../reference/settings.md#per-game)。
