# 游戏来源与分组

游戏库会认出每个游戏来自哪里：模拟器（显示模拟器的名字）、重编译 / 移植、PC 游戏、Xbox 或其他。游戏库上方的分类可以按来源筛选，列表视图里每个游戏名下方也写着来源。

分类和分组旁边的标志是模拟器、重编译和 Xbox App 自己的图标，直接从这台电脑上装好的程序里读出来；程序不在这台电脑上时只显示名字。

![按来源筛选和分组的游戏库](/screenshots/zh-CN/library-sources.png)

- **筛选**：点上方的「全部」「Dolphin」「重编译 / 移植」「PC 游戏」……只看这一类，后面的数字是游戏数。
- **显示选项**：「按来源分组」把游戏库按来源分成几组；关掉「显示分类」可以隐藏上方的分类（同时取消筛选）。
- **整组操作**：分组后，每组标题旁边有「全部同步」和「全部备份」。全部备份会给每个游戏建一个永久保留的手动备份，可以写一句备注，比如「升级模拟器前」。正在运行或没有存档的游戏会跳过。

## 自己指定分组

来源是自动识别的。想换个分法，在游戏详情页「设置」里填「来源分组」，例如填模拟器的名字，同一个模拟器的游戏就会放在一起；留空则自动识别。

这个名字只影响游戏库怎么分组。存档、游戏本体备份和成就用什么规则，仍然按 Ludonimbus 认出的模拟器或游戏来定。
