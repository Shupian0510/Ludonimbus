# 扫描本机

点游戏库右上角的「添加游戏」，第一个标签就是「扫描本机」。它会一次列出这台电脑上能添加的游戏，勾选后批量添加，不用自己找存档。

<!-- screenshot: add-game-scan -->

## 会找哪些游戏

| 来源 | 说明 |
|---|---|
| Steam 快捷方式 | 你加进 Steam 的非 Steam 游戏。有多个 Steam 账号时，可以在上面切换账号 |
| Epic、GOG、Xbox | 这些平台安装的游戏，包括 Xbox 应用（PC Game Pass）的游戏 |
| RecompLauncher | 用 [RecompLauncher](https://recomplauncher.com/) 安装的重编译游戏 |
| 模拟器里的存档 | 模拟器里有存档的游戏，逐个列出，不需要先建 Steam 快捷方式。见[模拟器](../supported/emulators.md) |
| 找到存档 | Ludusavi 数据库里、这台电脑上已经有存档的 PC 游戏。这一步大约需要半分钟 |
| 文件夹 | 用「扫描文件夹…」在你指定的文件夹里找到的游戏，见[扫描文件夹](./scan-folder.md) |

同一个游戏从几个来源都找到时（例如 Epic 装的游戏，Ludusavi 又找到了它的存档），只会列一次。

## 结果怎么分组

- **可以直接添加**：已经知道存档在哪里（内置规则或 Ludusavi 数据库）。可以「全选」。
- **需要指定存档位置**：Ludonimbus 还不知道这些游戏把存档放在哪里，点「指定存档…」，用[找存档向导](./save-finder.md)一步步找。
- **Steam 云已经在同步**：这些游戏现在装在 Steam 里，Steam 云存档已经在同步它们，一般不需要再添加；想多备份一份也可以勾选。
- **存档在注册表里**：存档写在 Windows 注册表里的游戏，暂不支持同步。
- **已经添加**：库里已经有了。

每个游戏下面会显示一些标签：

| 标签 | 意思 |
|---|---|
| 已识别：… | 被内置规则认出，例如某个模拟器或重编译游戏 |
| Ludusavi 知道存档位置 | 存档位置来自 Ludusavi 数据库 |
| 找到游戏位置（Epic…） | 只找到存档的游戏，在这个平台的安装目录里找到了游戏程序 |
| Steam 已安装 | Steam 里装着这个游戏 |
| 存档很大，可能含有缓存 | 存档超过 200 MB，可以点「查看」确认里面是什么 |

「本机有 N 个存档文件」是这台电脑上现在的存档。「没有找到游戏程序（可能已卸载）」的游戏也能添加：存档照样能同步，以后可以在详情页设置游戏位置。

游戏多的时候，可以在上面的输入框里筛选游戏名。

## 添加

勾选要添加的游戏，点底部的「添加到 Ludonimbus」。

刚添加的游戏如果还不在 Steam 里，上方会提示「……还不在 Steam 里」，点「加入 Steam…」可以一起加进 Steam，从 Steam 启动就会自动同步存档。见[一键加入 Steam](../steam/add-to-steam.md)。

已经在 Steam 里的游戏，添加后到详情页打开「Steam 自动同步」，见 [Steam 自动同步](../steam/auto-sync.md)。

## 「添加游戏」里的其他标签

- **云端已有**：其他电脑上传过、但这台电脑还没添加的游戏，见[多台设备](../sync/devices.md)。
- **Ludusavi 数据库**：按游戏英文名搜索，见 [PC 游戏](../supported/pc-games.md)。
- **手动添加**：自己选择游戏程序或存档文件夹，见[手动添加](./manual.md)。

## 没找到我的游戏

- 游戏放在别的文件夹：点「扫描文件夹…」。
- 游戏还没存过档：Ludusavi 只能找到已经有存档的游戏，先玩一下，或者用[手动添加](./manual.md)。
- 都不行：用[手动添加](./manual.md)，配合[找存档向导](./save-finder.md)的「玩一下再找」。
