# 界面设计规范（1.0 · 2026-11-28）

> 1.0 界面重构定下的设计规范：原则、尺寸和颜色、组件、布局、对照例子。规则的来由见 `plan-v2.md` §10.1；组件的代码在 `app/src/components/kit.tsx`，样式在 `app/src/styles.css`（文件开头是变量，末尾是组件）。

## 1. 原则

| 原则 | 做法 |
|---|---|
| **展示，不讲述** | 一件事实（哪个平台、哪台设备、什么时候、新了多少、多玩了多久、多大）是一个组件，放在固定的位置。不用「·」把几件事实连成一句话 |
| 少字 | 页面上不放解释性的段落；「这是做什么的」放进标题旁的「?」 |
| 关键操作才弹窗 | 只有覆盖本机存档、删除才问；其余直接做，做完给一条能撤销的提示，或者页面上的一行 |
| 一行一个主操作 | 每行只有一个带字的按钮，其余是图标按钮（悬停显示名字）或收进「更多」。一页只有一个蓝色主按钮 |
| 不加动效 | 没有过渡和动画，悬停只换颜色、加描边。只有加载中的转圈会动 |
| 真实图标 | 程序（模拟器、重编译、Xbox 应用、商店）的标志读自程序本身；本机没有这个程序时只写名字。设备种类（台式机、笔记本、掌机、Steam Deck、Switch）是通用的形状图标 |
| 封面干净 | 封面上不放任何东西；分类可以隐藏 |

## 2. 变量

**颜色**（深色，接近 Steam）

| 用途 | 变量 |
|---|---|
| 背景 / 面板 / 线 | `--bg` `--bg-2`、`--panel`、`--line` |
| 文字：主 / 次 / 弱 | `--text`、`--text-2`、`--muted` |
| 强调（主按钮、较新、本机） | `--accent`、`--accent-2`；`--newer` 就是强调色 |
| 状态 | `--ok` 绿（已同步、当前、多玩了）、`--info` 蓝（待上传、云端较新）、`--warn` 黄（冲突、不完整）、`--bad` 红（出错）；做文字时用 `--ok-text` 等浅一档的 |

**字号**：`--fs-caption` 11.5 · `--fs-small` 12.5（事实、标记）· `--fs-body` 14 · `--fs-title` 16（面板标题、设备名）· `--fs-big` 22（存档卡片上的时间）· `--fs-page` 26（页面标题）。数字一律等宽数字（`tabular-nums`），列对得齐。

**间距**：4 的倍数，`--sp-1` 4 … `--sp-6` 32。页面左右 32，面板内 16–18，一行里的事实之间 10–16。

**圆角**：`--radius-sm` 6（标记）· `--radius` 10（面板、行、卡片）· `--radius-lg` 14（掌机上的卡片、对话框）。标记和状态是胶囊形。

## 3. 组件

| 组件 | 显示 | 用在 |
|---|---|---|
| `Pill` | 状态：一个色点和名字（已同步、云端较新、两边都改过、本机、需要更新） | 操作栏、游戏卡下、列表、设备卡 |
| `PlatformMark` | 程序的真实图标和短名（Steam、Xbox、Ryujinx、GOG 版）；没有图标时只有名字 | 存档行第一列、组头、版本条、启动前的问题 |
| `DeviceChip` | 设备种类图标和名字；本机的图标是强调色，悬停写「（本机）」 | 存档行、组头、状态行、冲突卡片、成就、备份 |
| `When` | 多久以前；悬停是日期和时间 | 所有时间 |
| `Delta` | 和这里的比：↑ 新多少（强调色底）、↓ 旧多少（弱）、✓ 相同 | 存档行的比较列、提示行、掌机 |
| `PlayDelta` | 多玩了多久：⏱ +1 小时 20 分（绿） | 同上、存档卡片 |
| `Stat` | 一个图标和一个值（文件大小、游戏时长、游戏数）；悬停说是什么 | 状态行、设备卡、找存档、备份 |
| `ConvertChip` | 「需要转换」虚线小标记，怎么转换在它的「?」里 | 来源组头、提示行、启动前的问题 |
| `SaveCard` / `SaveCompare` | 一份存档一张卡：平台、时间（大字）和日期、设备、时长、大小；较新的一张描强调色边、带「↑ 较新」。两张并排，从那边到这里时中间一个箭头 | 启动前的问题、冲突、掌机上的「有更新的进度」和选存档 |
| `SourceHead` | 一组存档的头：平台标志和名字、设备、最新时间、需要转换、「?」 | 「存档」页签、掌机 |
| `Bars` / `Meter` | 按比例的条：每台设备玩了多久；云盘用了多少 | 只在云端的游戏页、设置 → 云盘 |

`ui.tsx` 里原有的照旧：`Button`（主按钮只用于每页最重要的一件事）、图标按钮 `icon-btn` / 大一号的 `icon-btn-lg`、`Hint`（「?」）、`Menu`（「更多」）、`Badge`（标签：当前、保留、不完整、替换前、实验性）、`Modal`、提示（toast，可撤销的带「撤销」）。

**Pill 和 Badge 的分别**：Pill 是「现在怎么样」（状态，带色点）；Badge 是「它是什么」（属性标签，不带点）。

## 4. 布局

- **页面**：标题 26 加一句副标题；右上是这一页的操作，主按钮在最右。游戏库的「刷新」是图标按钮。
- **游戏页**：头图（游戏没有图时只有 150 高，不留一大块空）→ 操作栏：一个主按钮（立即同步 / 取回），备份和打开文件夹是图标按钮，再是「更多」；右边是状态组件：状态 Pill、☁ 上次同步的时间和设备、🗎 本机存档大小、⏱ 总时长 → 提示行（有更新的进度、冲突、换成了…）→ 版本条 → 面板 → 页签。
- **存档行**：所有行同样的列：平台 | 时间（保留的存档是名字，后面是标记）| 设备 | 比较（新多少、多玩了多久）| 大小 | 主操作 · 保留 · 更多。这里的存档只在比当前新时才显示比较；别处的存档新旧都显示。
- **提示行**：一行组件，不是一句话。例：`[GOG 版] [笔记本 LAPTOP] 20 分钟前 [↑ 30 分钟] [⏱ +1 小时] → PC 版（这里）50 分钟前 [需要转换 ?]  [取回] [不用]`。
- **对话框**：一句标题；要比较的放成卡片；承诺（「现在的会先保留，可以撤销」）是一行带盾牌图标的小字。
- **设置**：顶部一排分节标记，点一下跳到那一节，滚动时一直在上面。
- **掌机界面**：同一套组件，在 `.hh` 下放大（字 16–19，标记 28 高，卡片时间 32），行是同样的列；按钮带手柄键位。

## 5. 对照

| 地方 | 以前（讲述） | 现在（展示） |
|---|---|---|
| 启动前的问题 | `GOG 版 · LAPTOP · 今天 21:14 · 多玩了 1 小时` / `PC 版（这里）· DESKTOP-MAIN · 今天 20:44` / 一段说明 | 两张存档卡片，左边较新的描边带「↑ 较新」，中间箭头；「需要转换」是小标记；按钮带 A / X / B；按钮下一行盾牌小字 |
| 游戏页状态 | `已同步 上次同步 35 分钟前 · DESKTOP-MAIN · 本地 14 个文件，1.2 MB` | `● 已同步` `☁ 35 分钟前 🖥 DESKTOP-MAIN` `🗎 1.2 MB` `⏱ 20.7 小时`，文件数在悬停里 |
| 冲突 | 一段话写两边的时间和大小，按钮在右 | 「两边都改过 ?」，下面云端、本机两张卡片，按钮各在自己的卡片里 |
| 存档页签 | 别处的行第一列是「新 30 分钟」文字 | 第一列永远是平台；比较是独立的一列：`↑ 30 分钟` `⏱ +1 小时` |
| 和云端不一样 | `两边都改过 · GPD-Win-Mini · 5 小时前` | 游戏图标、名字、`● 两边都改过`、设备、时间，对齐成列 |
| 设备页 | `最后在线 1 分钟前（2026-11-28 01:28）· Ludonimbus 1.0.0 · windows x86_64` | 设备种类图标、名字、`● 本机`；`⏱ 1 分钟前` `v1.0.0` `Windows` |
| 版本条 | `Longshot · 本机` | `[图标] Longshot ┊ 🖥 本机 ▾` |

**不要**：在一行里用「·」连三件以上的事；把状态写成句子（「从 Steam 启动时会自动同步」——开关已经说了）；同一页放两个蓝色按钮；为了好看加过渡。

## 6. 做新界面时

1. 先列出这一处要让人看到的事实，每件找上面对应的组件；没有对应的，先想能不能用 `Stat`，确实需要再加组件，写进本文第 3 节。
2. 事实放进固定的列或固定的顺序：平台 → 时间 → 设备 → 比较 → 大小 → 操作。
3. 解释写进「?」，承诺写成一行带图标的小字，警告用黄色的一行。
4. 中文和英文都看一遍有没有溢出（`?lang=en`）；掌机界面看一遍（`?handheld`）。
5. 浏览器预览的场景（`?scene=…`、`?prompt=newer`、`?prompt=conflict`、`?handheld&scene=handheld-game`）见 `app/src/scene.ts` 和 `scripts/docs-screenshots.ps1`。
