# 多语言 / Interface languages

Ludonimbus 目前支持简体中文和英文。语言在「设置 → 语言 / Language」里选择，默认跟随 Windows 显示语言（`zh-*` 用中文，其他用英文）。选择保存在 `config.json` 的 `language`（`system` / `zh-CN` / `en`），界面、托盘、启动前弹窗、Steam 插件都用同一个设置。

## 文案在哪里

| 部分 | 位置 | 写法 |
|---|---|---|
| 界面 | `app/src/i18n/zh-CN.ts`（原文）、`app/src/i18n/en.ts` | 每个组件一个命名空间；带参数的文案是函数。`en.ts` 的类型来自 `zh-CN.ts`，少一条或多一条 `tsc` 都会报错 |
| Rust（报错信息、启动前弹窗、托盘、导出对话框） | 写在使用的地方 | `tr!("中文 {name}", "English {name}", 参数…)`，见 `crates/core/src/i18n.rs`。读取配置时自动应用语言 |
| Steam 插件 | `plugin-millennium/frontend/status.ts` 的 `TEXTS` | 跟随 Ludonimbus 的设置（本机接口的回复里带 `lang`），Ludonimbus 没运行时跟随 Steam 的语言 |
| 规则文件的 `platform` | `adapters/*.yaml` | 写中文；英文由 `Adapter::platform_label` 翻译几个固定词（模拟器、移植…），新增词要在那里补上 |
| 更新说明 | `CHANGELOG.md` | 每个版本都有 `### 中文` 和 `### English`，应用里只显示当前语言那一段 |
| 命令行 | `crates/cli` | 只给开发者用，不随安装包发布，暂时只有中文 |

日志不翻译。

## 预览和测试

- 浏览器预览（`npm run dev`，示例数据）：地址后加 `?lang=en` 或 `?lang=zh-CN`；`?guide` 显示首次使用引导。
- Rust：`LUDONIMBUS_LANG=en` 让「跟随系统」按英文处理。测试里检查报错文字时要两种语言都接受（CI 是英文系统）。

## 增加一种语言

1. 复制 `app/src/i18n/en.ts` 为新文件（例如 `ja.ts`），翻译所有文案；在 `app/src/i18n/index.tsx` 的 `Lang`、`LANGS`、`catalogs` 里加上，并调整 `systemLang()`。
2. Rust：`crates/core/src/i18n.rs` 的 `Lang` 加一项，`tr!` 改成接受第三种语言（或者改用按 key 查表的方式），再补全所有 `tr!` 调用。这一步工作量最大，届时再决定。
3. Steam 插件：`status.ts` 的 `TEXTS` 加一份。
4. 安装程序：`app/src-tauri/tauri.conf.json` 的 `nsis.languages`。
5. 文档网站和 README 视需要补充。
