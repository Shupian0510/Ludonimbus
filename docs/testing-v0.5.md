0.5 新增：英文界面（设置里可以切换）、首次使用引导、通过 OpenList 一键连接夸克网盘。设计见 [plan-phase3.md](plan-phase3.md)。

测试版的版本号还是 0.4.0（还没改版本号），覆盖安装即可，应用内更新不会提示。日志在 `%APPDATA%\Ludonimbus\logs\`。

## 已经自动验证过的

- 前端：所有文案都有中英两份，英文版少一条 `tsc` 就会报错；浏览器预览（示例数据）里中英文的游戏库、详情、添加游戏、设置、更新提示、首次使用引导、夸克卡片的连接流程都点过，控制台没有报错。
- Rust：报错信息用 `tr!` 写成两种语言；中文和英文系统语言下（`LUDONIMBUS_LANG`）全部测试都通过。
- 夸克：
  - 本机用 OpenList 的本机存储代替夸克，跑通从 zip 安装（校验 SHA-256）、启动、挂载、受限的 WebDAV 账号、直接上传不留临时文件、刷新后能看到外部改动、停止后再启动、断开后删掉数据和密码（`tests/openlist_local.rs`）。
  - 你的夸克账号，两台设备（两个 OpenList，同一个登录）：读新文件、读覆盖后的内容、列出另一台设备新建文件夹里的版本、下载、删除都正确（`tests/quark_live.rs`，2026-11-23 通过）。

## 需要在真实环境确认的

### 1. 语言

1. 安装后打开 Ludonimbus：界面语言和 Windows 显示语言一致（中文系统就是中文）。
2. 「设置 → 语言 / Language」选 English：界面立刻变成英文，当前页面不跳走。托盘右键菜单变成「Open Ludonimbus / Quit」。
3. 英文状态下随便做几个操作（立即同步、打开一个游戏、改一个设置），看提示和报错是不是英文。看到中文或者不通顺的英文记下来（截图最好）。
4. 打开 Steam 的一个 Ludonimbus 游戏页：「开始游戏」栏的状态是英文（Ludonimbus Cloud Saves）。切回中文后，过几秒变回中文。
5. 关掉 Ludonimbus 再打开：语言保持你选的。选回「跟随系统」。

### 2. 首次使用引导（用临时数据目录，不动你现在的配置）

正常情况下，已经在用的用户不会看到引导。要模拟新用户，先在托盘里退出 Ludonimbus，然后在 PowerShell 里运行：

```powershell
$env:LUDONIMBUS_HOME = "$env:TEMP\ludonimbus-fresh"; & "$env:LOCALAPPDATA\Ludonimbus\ludonimbus-app.exe"
```

这个窗口用的是全新的配置（没有云盘、没有游戏），关掉后删掉 `%TEMP%\ludonimbus-fresh` 即可，你原来的配置不受影响。

1. 打开就弹出引导。第一页右下角的语言切换能用。
2. 选用途：可以多选，选「在多台设备之间同步存档」后，下一页的说明会变。
3. 连接云盘：中文界面第一个是「夸克网盘（实验性）」，然后是坚果云、Google Drive，「更多云盘…」里是其他的。这一步可以先跳过（下面第 3 节专门测夸克）。
4. 封面：没填 Key 时显示获取步骤，「打开 SteamGridDB 的 API 页面」能打开；可以跳过。
5. 完成页：已配置和跳过的项目显示正确；「在 GitHub 上点 Star」打开仓库页；「扫描本机游戏」关闭引导并打开「添加游戏 → 扫描本机」。
6. 关掉再打开：引导不再弹出。「设置 → 关于 → 重新打开新手引导」能再打开它；同一行的文档、GitHub、反馈问题链接能打开。

### 3. 夸克一键连接（建议先在第 2 节的临时数据目录里测）

1. 「设置 → 云盘 → 夸克网盘（实验性）」：显示需要下载 OpenList 组件（约 57 MB）和许可证。
2. 可以直接点「下载组件并连接」（从 GitHub 下载，有进度条），也可以点「选择已下载的安装包…」，选 `%LOCALAPPDATA%\Ludonimbus-e0\openlist-windows-amd64.zip`（实测时下载的那份）。
3. 弹出「登录夸克网盘」窗口，显示夸克网盘的官方网页。用夸克 App 扫码登录：登录后窗口自动关闭，设置页显示「已连接夸克网盘：夸克网盘 · Ludonimbus」。**这一步最需要确认**：页面能不能正常显示、扫码后窗口会不会自动关闭。记一下从扫码到显示已连接用了多久。
4. 再连接一次，这次在登录窗口里直接点关闭：应显示已取消，不报错。也试一次「取消」按钮。
5. 添加一个游戏（临时目录里可以用「手动添加」选一个有存档的小游戏），点「立即同步」：能上传，版本历史里出现版本。夸克网盘网页版里能看到「Ludonimbus」文件夹。记一下上传用了多久。
6. 任务管理器里能看到 `openlist.exe`；在托盘里退出 Ludonimbus 后，它也跟着退出。
7. 「断开」夸克：`%TEMP%\ludonimbus-fresh\openlist\data` 被删掉（里面有夸克的登录信息），`openlist.exe` 不再运行。

以下是可选的，确认上面没问题后再做（会改你真正的云盘设置）：

8. 在正常的 Ludonimbus 里改用夸克网盘：会问是否把原来云盘里的存档复制过来，复制能完成。
9. 不打开 Ludonimbus（托盘也退出），直接从 Steam 启动一个游戏，玩完退出：存档上传成功；游戏退出后 `openlist.exe` 也退出。
10. 用完换回原来的云盘。

### 4. 原有功能

1. 原来的云盘照常同步，从 Steam 启动游戏前后的拉取和上传正常。
2. 设置页其他云盘（Google Drive、WebDAV、S3）的表单显示正常（只看，不用重新连接）。

遇到问题时，把 `%APPDATA%\Ludonimbus\logs\` 里最新的日志（临时目录测试时在 `%TEMP%\ludonimbus-fresh\logs\`）和截图发给我。
