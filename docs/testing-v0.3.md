# 0.3 测试清单：更多云盘

0.3 新增：百度网盘一键登录、WebDAV、S3 兼容存储，以及换云盘时把旧云盘的存档复制过去。设计见 [plan-phase2.md](plan-phase2.md) 第 1 节。

日志在 `%APPDATA%\Ludonimbus\logs\`。WebDAV / S3 的密码保存在 Windows 凭据管理器里（「凭据管理器 → Windows 凭据」中名字以 `webdav:` 或 `s3:` 开头的条目）。没有快照属性的云盘会在 `%APPDATA%\Ludonimbus\cloud-cache\` 缓存版本信息。

## 已经自动验证过的

- `cargo test -p ludonimbus-core --test webdav_cloud`，在本机起一个真实的 WebDAV 服务（`dav-server`）：
  - 连接测试（写入、出现在列表里、读回、删除测试文件）；子文件夹自动创建；中文和空格路径；覆盖写入后变更标记会变；3 MB 文件上传下载一致；写完不留下临时文件。
  - 版本链、备注、锁定、删除版本、设备和游戏定义在 WebDAV 上都正常；再次列出版本时使用本地缓存，改了备注后能读到新内容。
  - 从文件夹云盘复制到 WebDAV：版本 id、父版本、备注都保留；只在本机配置里出现的游戏也会复制；再次复制时全部跳过。
  - 服务器连不上时按「离线」处理（启动游戏不受影响，之后补传）。
- `sync_flow`（两台设备、冲突、离线补传）在重构后的文件夹云盘上照常通过。
- S3 签名和 AWS 文档里的两个官方示例结果一致；对象地址的两种访问方式（虚拟主机 / 路径风格）。
- 百度网盘真实账号（`cargo test -p ludonimbus-core --test baidu_live -- --ignored`，开发者本人账号、应用未审核）：设备码登录、查询容量、不存在的文件夹 / 文件、自动创建子文件夹、覆盖写入、9 MB 三个分片上传、下载、删除文件和文件夹都通过。非会员下载约 80 KB/s。
- `cargo test -p ludonimbus-core --test baidu_cloud`，用按官方文档写的模拟 xpan 服务：设备码授权（先返回两次「尚未授权」）、取消登录、自动创建应用目录和子文件夹、4 MB 分片和 MD5 列表、9 MB 文件上传和经过 302 跳转的下载（要求 `User-Agent: pan.baidu.com`）、覆盖写入、删除、access token 失效后自动刷新且旧的 refresh token 作废、从文件夹云盘复制到百度网盘、应用名称不对时提示「我的应用数据/<名称>」。
- 设置页（模拟数据）：WebDAV / S3 表单、常用服务的预填、测试连接结果、复制存档提示条。

## 需要在真实服务上确认的

### 0. 百度网盘

先按 [baidu-netdisk-setup.md](baidu-netdisk-setup.md) 注册应用。

1. 「设置 → 云盘 → 百度网盘」，开发版里先填 AppKey、SecretKey、应用名称，点「连接百度网盘」。
2. 浏览器应打开百度授权页面，设置页显示授权码和二维码。分别试一次：在浏览器里授权；用百度网盘 App 扫码授权。授权后几秒内设置页显示「已连接百度网盘：<网盘昵称>」和已用 / 总空间。
3. 如果浏览器页面没有自动填好授权码，记下来（需要手动输入时也能完成即可）。
4. 网盘「我的应用数据/Ludonimbus」里出现文件夹；同步一个游戏后出现 `games/<游戏>/snapshots/` 下的 `.zip` 和 `.json`。
5. 从 Steam 启动、退出一次游戏，记一下启动前检查和退出后上传大概几秒。
6. 等待授权时点「取消」应立刻停止；5 分钟不授权应提示超时。
7. 断开后凭据管理器里的 `baidu-pan-token` 条目应被删除。
8. 同步一个大一点的存档（例如 Bloodborne，约 15 MB）后在另一台电脑或删掉本地存档后拉取，记一下耗时。非会员下载被百度限速（实测约 80 KB/s），确认等待期间界面有提示、不会被当成卡死。

### 1. WebDAV

至少试一种，能试几种就试几种：坚果云、群晖 WebDAV Server、OpenList / AList（挂载一个国内网盘）、Nextcloud。

1. 「设置 → 云盘 → WebDAV → 填写 WebDAV 信息…」，点对应的「常用」按钮，把地址里的 `<…>` 换成真实值，填用户名和密码。
2. 点「测试连接」：应显示「连接成功：<地址>/Ludonimbus」，服务器支持时还会显示已用空间。故意填错密码，应提示「用户名或密码不对（401）」。
3. 点「连接」。之后在服务器上应能看到 `Ludonimbus` 文件夹（坚果云网页版、群晖 File Station、OpenList 网页）。
4. 立即同步一个游戏，服务器上出现 `games/<游戏>/snapshots/<id>.zip` 和同名 `.json`，没有残留的 `.lntmp` 文件。
5. 从 Steam 启动、退出一次游戏，确认启动前检查和退出后上传都正常，耗时可以接受（记一下大概几秒）。
6. 打开游戏详情的版本列表：时间、设备、备注都正常；改备注、锁定、恢复旧版本都能用。

**需要特别留意**：
- 坚果云免费账号有请求频率限制，连续同步几次后是否出现「服务器繁忙或请求太频繁」。
- OpenList / AList 挂载的网盘上传后，网盘里的文件大小是否正确，过一会儿再列出是否还在（有些驱动有延迟）。
- 群晖用 `https://…:5006` 时，如果证书是自签名的，应提示证书无法验证并建议用 `http://`，而不是笼统的「暂时无法访问」。

### 2. S3 兼容存储

有条件时试一种：NAS 上的 MinIO、阿里云 OSS、腾讯云 COS 或 Cloudflare R2。

1. 「S3 兼容存储 → 填写 S3 信息…」，点对应的「常用」按钮，填 Endpoint、Bucket、Access Key、Secret Key。MinIO 打开「路径风格」。
2. 「测试连接」成功后再「连接」，同步一个游戏，在控制台里看到 `Ludonimbus/games/…` 下的对象。
3. 故意填错 Secret Key，应提示「Secret Key 不对」；填错区域，应提示区域或访问方式不对。

### 3. 换云盘并复制存档

1. 当前连着 Google Drive（或文件夹），里面有几个游戏的多个版本。
2. 连接 WebDAV，确认「改用 WebDAV？」对话框。
3. 云盘区域顶部应出现「要把原来云盘里的存档复制过来吗？」。点「复制存档」，进度条显示「正在复制 x / n：<游戏>」，完成后提示复制了多少个版本。
4. 每个游戏的版本列表和复制前一致（数量、时间、备注、锁定）；之后从 Steam 启动游戏应直接显示「已是最新」，不应提示冲突。
5. 复制中途断网：应提示「复制没有完成」，联网后再点一次只复制剩下的。
6. 再换一个云盘时点「不用了」：提示条消失，原来云盘里的数据不变。
7. 「断开」后，凭据管理器里对应的 `webdav:` / `s3:` 条目应被删除。
8. 从 Google Drive 换到百度网盘时同样会询问复制，复制后版本列表一致。
