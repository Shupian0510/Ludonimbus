## 需要在真实环境确认的

### 1. 测速（每种云盘各一次）

1. 用脚本测（不用装应用）：

   ```powershell
   ./scripts/cloud-speedtest.ps1 -Threads 2,4,8
   ```

   报告在 `%LOCALAPPDATA%\Ludonimbus-speedtest\`。测别的云盘时先在应用里切换过去再跑（切换时的「复制旧云盘的存档」可以选以后再说）。
2. 在应用里：「设置 → 云盘测速」选 200 MB、4 线程，点「开始测速」：进度条走完，显示上传 / 下载速度、10 GB 和 50 GB 的预计时间和结论。中途点「停止」能停下来。
3. 测完看云盘根目录：没有留下 `.ludonimbus-speed-` 开头的文件。

请把每种云盘的报告（`.txt`）发给我，我填进方案的 1.3 节，再按结果调整提示和默认并行数。

### 2. 备份一个小游戏

先选一个小的、不在 Steam 正版库里的游戏（例如几百 MB 的重编译游戏）。

1. 打开它的详情页，「游戏本体」卡片里显示游戏文件夹。点「计算大小」：文件数和大小合理，存档、日志被排除。
2. 点「备份到云端」：进度依次是扫描、查看云端、上传（已读取 / 已上传 / 速度 / 剩余时间）、核对、保存版本。完成后提示「备份完成，上传了 X MB」，卡片显示最新备份的时间和大小。
3. 再点一次「更新备份」：很快提示「游戏文件没有变化」。
4. 关掉窗口（托盘里还在）时备份不会中断；再打开窗口能看到进度。
5. 游戏运行时点备份：提示先退出游戏。

### 3. 更新后的增量备份、停止后继续

1. 改一点游戏文件（例如换一个 mod、改一个配置文件），点「更新备份」：只上传了很少的数据。
2. 备份一个大一点的游戏（几 GB），上传到一半点「停止」：提示已停止。再点「备份到云端」：前面上传过的部分不再上传（「已上传」比第一次少），最后成功。

### 4. 版本

1. 「版本（N）」展开能看到每个版本的时间、设备、大小。默认「保留最近 2 个版本」：备份第 3 个版本后最旧的自动删掉。
2. 删除一个版本：确认后删除，提示释放了多少空间。
3. 改成「全部」后不再自动删除。

### 5. 恢复到临时文件夹（不动真实游戏）

1. 点「恢复…」，选一个空的临时文件夹（例如 `D:\restore-test`），**取消勾选**「恢复后让 Ludonimbus 和 Steam 快捷方式指向新位置，并拉取云存档」（这一步只看文件对不对）。
2. 开始恢复：进度依次是准备、下载、校验、收尾，完成后提示恢复到哪里。
3. 对比文件夹：文件数、大小和原文件夹一致（存档、日志没有，存档文件夹是空的）。可以用 PowerShell 抽查几个文件：

   ```powershell
   Get-FileHash D:\restore-test\<某个文件>; Get-FileHash <原游戏文件夹>\<同一个文件>
   ```

4. 再恢复一次，下载到一半点「停止」，然后点卡片上的「继续恢复」：从断点继续，最后成功。
5. 选一个不是空的文件夹：恢复对话框显示「文件会放到：<文件夹>\<游戏文件夹名>」。
6. 测完删掉 `D:\restore-test`。

### 6. 本体缺失后从云端安装（Ludonimbus 里）

不要删游戏，**把游戏文件夹改个名字**来模拟（测完改回来）：

1. 退出游戏，把游戏文件夹改名（例如加 `-bak`）。
2. 打开 Ludonimbus 的详情页：卡片显示「本机没有文件」和「从云端安装…」。
3. 点「从云端安装…」，选一个新文件夹，**保持勾选**修正路径和拉取存档，开始恢复。
4. 完成后：「游戏位置」指向新文件夹；提示里有「已拉取云存档」；从 Ludonimbus 或 Steam 启动游戏能正常玩，存档是最新的。
5. Steam 快捷方式：
   - 开了「Steam 自动同步」的游戏（快捷方式经过 `ludonimbus-run`）：不用改，直接能从 Steam 启动。
   - 没开的：如果 Steam 开着，卡片显示「更新 Steam 快捷方式」，点它会提示关闭 Steam，确认后快捷方式指向新位置，Steam 自动重新打开。
6. 改回去：删掉新文件夹，把原文件夹名字改回来，在「游戏位置」点「重新选择…」选回原来的程序（或「自动查找」）。

### 7. Steam 插件：从云端安装

需要第 6 节的状态（游戏文件夹改了名，云端有备份），并且 Steam 插件已经更新、Steam 重启过。

1. 在 Steam 游戏库里打开这个游戏的页面：「开始游戏」栏的 Ludonimbus 状态显示「本机没有游戏文件 · 点击从云端安装」，鼠标悬停显示备份的时间、设备和大小。（第一次打开可能先显示原来的状态，几秒后变成这个：Ludonimbus 在后台查询云端。）
2. 点击：Ludonimbus 窗口打开到这个游戏，恢复对话框已经打开。
3. 开始恢复后回到 Steam：状态显示「正在从云端安装 X%」并在变化；完成后变回正常的云存档状态。
4. 英文界面下同样的文字是英文。

### 8. 慢的云盘（百度网盘 / 夸克网盘）

1. 当前云盘是百度网盘时，卡片显示「百度网盘非会员下载约 80 KB/s：以后恢复 X 预计要 Y」。第一次备份一个游戏时弹出确认框，说明要多久；点「仍然备份」才开始。恢复对话框里也有这条提示。
2. 夸克网盘：卡片和第一次备份的确认框里显示上传的预计时间。
3. 实际速度和提示差太多的话告诉我（附第 1 节的测速报告）。

### 9. Google Drive

1. 测速能跑通，测试文件删干净。
2. 第 2、5 节在 Google Drive 上各做一遍。云端硬盘里能看到 `Ludonimbus\gamebackup\<游戏>\` 文件夹。

### 10. 两台设备（如果有）

1. 电脑 A 备份一个游戏；电脑 B 上同一个游戏（或「添加游戏 → 来自云端」加进来）的卡片显示 A 的备份，从云端安装到 B，能玩、存档是最新的。
2. A 正在备份时，B 点备份：提示「A 正在备份这个游戏」。
